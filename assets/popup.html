Before connecting

Requested messages, profiles and post data pass through the local MCP bridge to your chosen MCP client. That client may send data to its AI provider. No product telemetry is collected.

Requested write operations execute directly, without an extension confirmation. Install the MCP bridge from Git on macOS or Windows, configure your local MCP client, then open LinkedIn and connect. The bridge creates its own work tab and brings it forward for scrolling and UI actions.
