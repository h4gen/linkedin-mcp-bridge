# Store gallery explainers

Five 1280 × 800 RGB PNGs in the accepted ivory/navy/cobalt campaign style, generated with built-in image_gen. Exact prompts: prompts.json. Source images are preserved in source/. Export with export.cjs and sharp (NODE_PATH if needed).

- upload/inbox-1280x800.png: message search, context, replies and organization.
- upload/research-1280x800.png: profile research, native text drafts and post scheduling.

These are promotional capability explainers for the store gallery, not screenshots of an application UI. Original popup captures remain in store/screenshots/ as historical source material.

- upload/people-1280x800.png: people search and meeting preparation.
- upload/feed-1280x800.png: posts, comments and reactions.
- upload/publishing-1280x800.png: text drafts, scheduling and cancellation.
